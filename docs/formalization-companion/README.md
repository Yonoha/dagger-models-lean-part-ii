# English Part II formalization catalogue

The PDF is an AI-generated companion catalogue for Part II Theorem C and eight
grouped theorem/proposition-level supporting results. Its first page explicitly
states that its prose and result summaries were generated by AI agents.
The principal notation follows Part II, including the direction of each adjoint.

The fonts follow the existing Part I companion: Latin Modern text and standard
LaTeX mathematical fonts. No CJK fallback is used for the English text.

Build with LuaLaTeX:

```sh
latexmk -lualatex -interaction=nonstopmode -halt-on-error -outdir=../../build/catalogue main.tex
```

Copy the resulting PDF to `part2-theorem-c-companion-en.pdf` in this directory.
The release also distributes that PDF as a direct-download asset.
The catalogue distinguishes saved local kernel verification from a fresh full
build, hosted CI, Comparator and independent human review.
